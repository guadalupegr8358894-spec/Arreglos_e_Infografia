¿En qué consiste mi programa?
Este programa crea una matriz con las calificaciones de 500 alumnos en 6 materias. Las calificaciones se generan de manera aleatoria del 5 al 10. Después, busca la calificación de un alumno específico y mide el tiempo que tarda en realizar la búsqueda. También realiza pruebas con matrices más grandes.
¿Cómo funcionan los métodos?
buscar_calificacion()
Sirve para buscar la calificación de un alumno en una materia determinada.
probar_con_volumen()
Sirve para crear matrices de diferentes tamaños y comprobar cuánto tiempo tarda el programa en buscar una calificación.
time.perf_counter()
Se utiliza para medir el tiempo que tarda en ejecutarse la búsqueda.
